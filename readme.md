## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:

    ```sh
    git clone https://github.com/your-username/task-management-app.git
    cd task-management-app
    ```

2. Install dependencies:

    ```sh
    npm install
    ```

## Running the Project

To start the development server, run:

```sh
npm run dev
